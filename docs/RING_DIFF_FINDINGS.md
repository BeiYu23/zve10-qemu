# 命令环差分实验（0x20312000）

## 一、分块哈希定位（512 块 × 64KB，扫全 32MB）

**两轮 DOWN 后的变化块：**

```
第 1 次 DOWN (11 块): #0,#1,#2,#5,#6,#7, #37,#38,#39,#40,#41
第 2 次 DOWN (14 块): #0,#1,#2,#3,#4,#5,#6,#8,#9, #37,#38,#39,#40,#41
```

**★★★ 部分块的哈希**回到原值**：**
```
块 #1:  b7ee0345 -> a3a17945  (第1次)
块 #1:  a3a17945 -> b7ee0345  (第2次)  ← 恢复
块 #2:  834b4595 -> 6be22395
块 #2:  6be22395 -> 834b4595  ← 恢复
```

**⇒ **双缓冲**：两套描述符交替使用。**

**变化集中在两个区域：**
- **区域 A：块 #0-#9   = off 0x000000 - 0x0009FFFF（前 640 KB）**
- **区域 B：块 #37-#41 = off 0x00250000 - 0x0029FFFF（2.5 MB 附近）**

## 二、块 #0 的结构（前 64 个非零 u32）

```
+0x0004  0x000001e3          ← 483（条目数？）
+0x0008  0x00000008          ← 8
+0x0014  0x01d79ec0
+0x0018  0x80312000          ← 自指（环基址 + 0x60000000）
+0x0020  0x80598118
+0x0024  0xffffffff          ← sentinel
+0x0028  0xffffdadd          ← sentinel
+0x002c  0x35f92838          ← 校验/魔数
+0x0038  0x80312030  0x80312030   ← 成对重复
+0x0040  0x80312038  0x80312038
+0x0048  0x80312040  0x80312040
+0x0050  0x80591cf0
+0x0054  0x803121e0          ← 指向环内
+0x0058  0x80312050  0x80312050
+0x0060  0x8059a460  0x8059a460
+0x0080  0x80312078  0x80312078
+0x00a0  0x80312098  0x80312098
+0x00a8  0x803120a0  0x803120a0
+0x00d0  0x803120c8  0x803120c8
+0x0100  0x803120f8  0x803120f8
```

**两种地址交替：**
- **`0x80312xxx` = 环内自指**（虚拟基址 0x20312000 + 0x60000000）
- **`0x8059xxxx` = 环外内核缓冲**（`0x80598118` 反复出现，疑为空槽占位）

**⇒ 描述符数组里既有环内偏移、又有外部 buffer 指针的标准布局。**
