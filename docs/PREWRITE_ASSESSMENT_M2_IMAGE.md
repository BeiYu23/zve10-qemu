## 二、⚠️ 一个我建议你重新决定的地方：`im.elf` / `bootin.elf`

**当前镜像里这两个文件是【ZV-E10 版】：**

| 文件 | 镜像内 | ZV-E10 | ZV-1M2 | 字节差异 |
|---|---|---|---|---|
| `im.elf` | `f1c746e3` | `f1c746e3` | `d2f47a82` | **13,725 B（59%）** |
| `bootin.elf` | `d8bfb4f7` | `d8bfb4f7` | `3545261c` | **2,481 B（16%）** |

### 2.1 `im.elf`：两版**服务启动顺序不同**

```
两版 NEEDED 完全相同（15 个）✅
字符串：共同 338 条

ZV-1M2 独有：                 （E10 对应项为另一种写法，未逐条列出）
  "a_thread APP idx err"
  "a_thread INFRA_END idx err"
  "i_thread INFRA_PARA idx err"
  "i_thread LIRO_END idx err"
```

**⇒ 差异集中在【服务启动序列/线程顺序】。
混合镜像运行的是整套 ZV-1M2 服务 ⇒ 从内部一致性看，`im.elf` 用 ZV-1M2 版更合理。**

**⚠️ 但反向也有理由：E10 的 `im.elf` 可能含 E10 专属硬件初始化。
两版字符串里没有出现明显的机型相关串，所以这一点无法从字符串判断。**

**⇒ 这是一个**未审计的决定点**，两条路都没有验证过。**
**⇒ 我不替你决定，但建议你明确记录选了哪一版、为什么。**

### 2.2 `bootin.elf`：字符串完全相同

```
字符串：E10 独有 0 条   M2 独有 0 条   共同 268 条（含 preload 白名单四项）
```

**⇒ 代码有 2,481 字节差异但没有任何字符串差异 ⇒ 属于同一份源码的重新编译。
沿用 ZV-E10 版风险较低。**
