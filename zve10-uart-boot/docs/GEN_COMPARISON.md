# 三代机(CXD90045) vs 四代机(CXD90057) 对比核对

| 项目 | ZV-E10 / A7C（CXD90045） | A6700（CXD90057） | 能否照搬 |
|---|---|---|---|
| 解锁值 | **V=0x8CB102DC, C=0xA86DA25E**（boot0 0x200） | UNLOCK=0x2CF25621 | ❌ 必须用本机值 |
| 记录组帧 | SET_UNLOCK → MEM_WRITE → SET_ENTRY → SET_UNLOCK（首末同 type） | END_MARKER(0x0123) 开头/结尾 | ❌ 用本机已验证帧 |
| 单条上限 | payload ≤ 4086 B（len≤0x1000） | 同样 4086 | ✅ 一致 |
| 装载地址 | 0xFE020000 | 0xFE020000 | ✅ 一致 |
| 入口 | Thumb 须 addr\|1（A7C: 0xFE020041） | 0xFE020000 | ⚠️ ARM 代码用偶数地址可行（已实测） |
| 串口波形 | 20.833 µs/bit（48000 baud）；慢块 250 µs（slow=12） | 相同 PIO、相同 clkdiv 公式 | ✅ 波形一致 |
| 前导 | 60 沿、慢块 225.4–293.6 µs | 相同（29 对 [23]/[22] = 250/239 µs） | ✅ 一致 |
| 组长度 | 建议 < 1.45 s（A7C 实测 1.2–1.35 s） | 20,992 B / 45 条 / 约 5 s 成功 | ⚠️ 四代机更宽松，三代机保守 |
| 触发方式 | `--cold`：轮询 GP28 等 D− 被拉高，再等 0.5 s 发整组 | 同样 sense 轮询 | ✅ 可采用 |
| 接线 | 只需 GP28→470Ω→D−（A7C 笔记未提 CC/VBUS） | CC 56k 上拉 + VBUS 5V | ⚠️ 机型不同，ZV-E10 已实测下拉可用 |
| 固件命令 | a7c_uart_boot（q/slow/fast 参数可调） | a6700_pio_od 2（sense/pull 命令） | ⚠️ 波形同，命令集不同 |
| payload 架构 | ARMv7 | ARM64 | ❌ 不通用 |

## 结论：可以借用 / 不可借用的部分

**可以借用（与 SoC 无关）**
1. **cold/sense 同步**：等 D− 被拉高再发，A7C 笔记也明确写了这个做法 ✅
2. **Pico 固件的 sense/pull 命令**（波形与我们的完全一致）✅
3. 记录编码函数（body+CRC32，len=10+payload）✅
4. 上电顺序：先开载波 → 再装电池 ✅

**不能借用（SoC 相关）**
1. UNLOCK 值 0x2CF25621 ❌（本机 0x8CB102DC）
2. END_MARKER 组帧 ❌（三代机必须 SET_UNLOCK 首末）
3. 他们的 ARM64 payload ❌
4. CC 上拉接线 ❌（本机已实测下拉可进串口启动）

## 三代机特殊约束（来自 A7C 笔记）
```
· 记录单条 ≤ 4086 B（超限 → 0x2004）
· 组首末 type 必须相同，否则 0x2004
· 组长度建议 < 1.45 s（timer A）
· 慢块必须在 225.4–293.6 µs（slow=11 → 229µs 失败；slow=12 → 250µs 成功）
· MEM_WRITE 地址无校验，写错地址当场挂死
```
