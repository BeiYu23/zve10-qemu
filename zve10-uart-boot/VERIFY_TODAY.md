## 二、核对笔记后的关键结论

### 2.1 必须"彻底断电"再测试

```
我们的 payload 会关闭看门狗，并进入死循环
⇒ 相机不会自己重启，ROM 也不会重新进入串口启动
⇒ 每次测试前必须：拔电池 + 断开 VBUS，等 10 秒
```

### 2.2 载波必须全程有边沿（记录阶段）

```
笔记：「组内不允许出现 >293.6 µs 的静默，否则 ROM 直接 0x3001/0x2004」
⇒ 记录阶段载波必须持续翻转（约 4 kHz）
⇒ 空闲载波只能用于"ROM 已经跳走之后"的数据阶段
```

### 2.3 不能加"载波后 0.5 秒等待"

```
笔记里的 TRANSMIT_START=0.5s 是配合他们那种"慢块前导"波形的
我们用的是翻转载波，多等 0.5 秒会被 ROM 当成垃圾帧 → 直接退出
实测：加了 0.5s 等待后 A 阶段必然失败，去掉后恢复正常
```

### 2.4 数据阶段需要干净线路

```
接收器靠"起始位下降沿"对齐
⇒ 载波翻转会产生伪起始位 → 无法对齐
⇒ 必须切到空闲载波（线路保持高电平）再发数据
⇒ 双模式固件 CMD_RAW(0x0C) 已验证可用
```

### 2.5 接收器设计要点（已实现）

```
· 用起始位宽度自动校准位时序（不依赖 CPU 频率）
· 测量与延时使用相同的"读 MISC 寄存器"循环，避免漂移
· 魔数 AA 55 AA 55 同步
· 头部 = addr(4) len(4) crc32(4) entry(4)
· 地址/长度合法性检查（0xFE000000~0xFE100000，len ≤ 256KB）
· CRC32（zlib 多项式）校验，结果用长闪报告：
    1 次长闪 = 通过 ; 3 次长闪 = 失败
· entry = 0xFFFFFFFF 表示"只校验不跳转"
```
